# T-186 — Chat icon: the speaking flask, wired into the site and the app

Engine: claude
Model: sonnet
Lane: web
Context: standard
Touches: apps/site apps/web packages/ui docs tasks
Needs: none
Checks: pnpm lint && pnpm typecheck && pnpm test && pnpm test:integration && pnpm test:fixtures && pnpm test:e2e

## Why

The support chat (T-175) has an approved icon, designed and signed off by Kumar on 2026-11-27: the Pactlab flask as a speaking face — the flask's curve forms a face in profile, mouth open mid-speech, gradient liquid inside, smoke curling from the flask's mouth. It carries the brand (flask, indigo gradient, the smoke motif from Pactlab Rinse) and says "talk to us" without a generic speech-bubble glyph. Reference renders are committed with this task at `docs/brand/chat-icon.webp` (right-facing) and `docs/brand/chat-icon-flipped.webp` (left-facing).

## Build

1. **Production artwork:** recreate the approved design as one clean SVG (transparent background) in the shared brand/UI asset location both surfaces consume: navy `#081127` linework, liquid gradient `#2A3AA8` → `#6978FF`, three smoke wisps from the flask mouth, the speaking face in profile. Match the reference renders; the rasters stay in `docs/brand/` as the design reference and are not shipped in the UI.
2. **Orientation rule (Kumar, 2026-11-27):** the website chat button sits bottom-right, so the site uses the **left-facing** artwork — the face looks into the page, toward the visitor and the chat panel. Any chat affordance placed on the **left** (in the app, if so placed) uses the **right-facing** artwork. One asset, mirrored by placement rule, not by ad-hoc flips.
3. **Wire it in:** replace whatever placeholder or generic icon the T-175 chat surfaces currently use — the public site's chat button and the in-app chat button/avatar — with this artwork, including the chat panel header if an avatar/icon appears there.
4. **Small-size legibility:** verify at 24, 32 and 48 px; if the face muddies at 24 px, simplify strokes for the small rendering rather than shrinking the detailed one.

## Acceptance

- Screenshot: the pactlab.ai chat button (bottom-right) shows the left-facing speaking flask.
- Screenshot: the in-app chat button shows the icon in the orientation correct for its placement.
- Both surfaces consume the single shared SVG asset; no raster icon ships in the UI.
