## Kumar's model (2026-11-26)

Per-deal pricing is **a fixed fee plus a variable that scales with deal size** — a $100M deal carries far more documents and complexity than a $10M deal, and one-size pricing ignores that. The variable is a small percentage of the deal's enterprise value on a declining scale, so it stays a modest addition, never the headline. This supersedes the earlier research position of never pricing as a percentage of deal value (docs/pricing-research.md is updated by this task to record the change and why).

## The schedule (config data in T-087's price book — Kumar tunes the numbers without code)

- **Fixed fee: $5,000 per pact** — the workspace, packs, evidence and findings machinery, with a base document/AI allowance.
- **Variable, on the deal's enterprise value:** 5 bps (0.05%) on the first $25M; 2 bps on $25M–$100M; 1 bp above $100M. **Variable capped at $50,000 per deal.**
- Worked totals: $10M deal → $5,000 + $5,000 = **$10,000**. $50M → $5,000 + $17,500 = **$22,500**. $100M → $5,000 + $27,500 = **$32,500**. $250M → $5,000 + $42,500 = **$47,500**. $500M → variable capped, **$55,000**.
- **Pilot stays flat $5,000, no variable** (the established pilot offer is unchanged).
- The variable carries the scale it prices: the included document count and AI budget for the pact step up with the variable bands (the actual cost driver), shown to the buyer at checkout as what's included.
- Venture Raise uses the same model on the raise size.

## Build

1. **Price book:** the fixed fee, bps bands, cap and pilot flat rate are price-book config (versioned like T-087's book and T-093's rates), never code constants. Checkout quotes the total with the fixed and variable lines shown separately — the buyer sees exactly what the size of their deal adds.
2. **Deal value basis:** the pact's enterprise value as declared when the pact is purchased (the same figure the pact's own IC/LOI surfaces use, which keeps it honest). No post-hoc true-up in this task: if Kumar later wants the variable trued to the valuation base case, that is a follow-on decision, recorded here as an explicit non-goal.
3. **Interactions:** the reseller 10% first-year discount (T-093) applies to the total; reseller commissions accrue on what's collected, variable included, with no T-093 change. Refunds follow T-087b's rules on the full collected amount.
4. **Currency:** the book is USD-denominated at launch; Stripe presents the buyer's currency at checkout. Regional price books (EUR/GBP/JPY/INR books) are a later Kumar decision — do not auto-convert the book under T-170; T-170's no-silent-conversion rule governs pact money, and this task records the distinction.
5. **Public copy:** the site may describe the shape ("a fixed per-deal fee plus a small size-based component — a $10M deal and a $100M deal don't cost the same") with the $5,000 fixed and the pilot flat rate; the full band table is shown at checkout and in the sales conversation, and the exact totals are never a secret from the buyer paying them. (T-093's rule stands untouched: reseller commission figures stay non-public.)
6. **Docs:** docs/pricing-research.md gains the adopted model, the worked table, and the note superseding the never-a-percentage position; the T-087 live-gate checklist (T-102) is updated to point at the price book values rather than open questions.

## Checks

- Quote tests at the band edges: $10M / $25M / $50M / $100M / $250M / $500M reproduce the worked totals exactly, cap included; pilot quotes flat $5,000 at every size.
- Checkout test: fixed and variable lines itemized; reseller discount applies to the sum; refund voids per T-087b.

## Acceptance

- A $100M pact quotes $32,500 itemized ($5,000 fixed + $27,500 variable) at checkout in Stripe test mode.
- Changing a bps value in the price book changes quotes with no deploy.
- docs/pricing-research.md records the adopted model.
