## Symptom (verified 2026-11-16/17)

Main CI fails at the step "Run pnpm test" on most merges since #209 (2026-11-16; #209 = T-126 PR 5, document library and AI review queue paged — the bisect window opens there, through #215). Main was green again on the evening of 2026-11-16, then red from #221 onward. On 2026-11-17 it also failed on three doc-only commits that changed nothing but task markdown files (ci #1058–#1060, the T-132/T-121/T-133 task filings) — incoming changes are therefore not the cause; the failure lives in the suite or in main's current state. Which spec fails is unknown: job logs are not reachable from the agent's GitHub connector, but this task runs on the Mac, where the suite and the Actions logs are both directly available.

## Job

1. Reproduce: run `pnpm test` on current main locally. Identify the failing spec(s) precisely — file, test name, failure output.
2. Classify the root cause: real regression, test-ordering/state leakage, time- or environment-dependence, or flake. If the failure is intermittent locally, run the implicated suites repeatedly and in isolation vs in the full run to separate ordering effects from deterministic failure.
3. If a regression: bisect the #209–#215 window (and #221 if the failure signature differs) to the introducing change, then fix at the root — in the code if the code is wrong, in the test if the test encodes a superseded contract.
4. Follow CLAUDE.md's testing principles: a deterministic failure gets fixed, never skipped or quarantined. Quarantine is only for a proven flake, and then only with the same-day owner + fix-or-delete discipline the principles require — and the PR must say which case this was and why.
5. Do not edit anything under `.github/workflows/`.

## Acceptance

- The failing spec(s) are named in the PR, with the root cause stated in one paragraph.
- `pnpm test` passes locally on main, and main CI is green on two consecutive runs after the fix merges.
- No test deleted or assertion weakened without a stated reason tied to a superseded contract.
