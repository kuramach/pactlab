## Why

T-006 shipped document upload, cited Q&A, contract extraction and named
review against an in-memory port; `DocumentsModule` was never mounted and
there were no tables. Increment 5's exit criterion ("every accepted AI
finding has exact citations and a human reviewer") held only in tests.

## Plan

1. **Migration `20261005000200_documents`** (expand-only): `documents`,
   `document_pages`, `ai_runs` (hashes and counts only — never prompt or
   document content), `document_findings` (citations JSONB), append-only
   `document_finding_reviews`.
2. **Database invariants:** object key carries the tenant/deal prefix;
   prohibited data classes (HR, compensation, performance, named
   contribution) must be `ai_excluded`; purge state consistent; a document
   finding must have ≥1 citation; leaving DRAFT requires a named reviewer
   and decision time.
3. **Privileges:** no DELETE; UPDATE limited to purge columns
   (`documents.status/purged_at`, `document_pages.text`) and decision columns
   on `document_findings`. AI runs and reviews insert-only.
4. **RLS:** documents follow the evidence boundary — contributors may upload
   and read SHARED documents only; pages are visible exactly when their
   document is; AI runs and document findings are buyer-side; reviewer ids
   must equal the caller.
5. **`PrismaDocumentsRepository`**: `withTenant`, change + audit in one
   transaction.
6. **Mount** `DocumentsModule` in `AppModule`. Adapters are injectable via
   `AppDependencies.documents`; omitted adapters fail closed (unavailable
   object store, scanner returning UNAVAILABLE → uploads rejected,
   `NotConfiguredClaudeGateway`). `main.ts` wires a local filesystem store
   (`DOCUMENT_STORE_DIR`, owner-only files, tenant-prefixed, no overwrite)
   and the signature scanner only when `APP_ENV=local`.
7. **Tests:** documents API suite runs on the production app + PGlite
   (in-memory repository removed; scripted model transport kept); DB tests
   for contributor boundary, isolation, decision attribution, invariants and
   immutability; adapter tests; real-Postgres cross-tenant case.

## Acceptance

- `/v1/deals/:id/documents`, `/questions`, `/document-findings` served by
  `AppModule`.
- Accepted document findings carry exact citations and a named reviewer,
  enforced by the database as well as the domain.
- Checks green.

## Rollback

Drop `document_finding_reviews`, `document_findings`, `ai_runs`,
`document_pages`, `documents` and the seven new enums.

## Out of scope (follow-ups)

- Bedrock `ModelTransport` (AI calls report NOT_CONFIGURED until wired).
- S3 object store and managed malware scanner for deployed environments.
