# T-017 — Marketing site from the brand kit

Status: done
Needs: none
Touches: apps/site .gitignore turbo.json .env.example pnpm-lock.yaml tasks

Checks: pnpm lint && pnpm typecheck && pnpm test && pnpm --filter @pactlab/site build

## Brief

Build the pactlab.ai marketing site from `brand/` (BRAND.md and logos).

## What

- `apps/site`: Next.js static export (`out/`), no server, no runtime
  requests to third parties (Manrope self-hosted by next/font).
- One page: hero (tagline, pillar, symbol), the evidence → integration
  action loop, four capabilities, "Claude assists. People decide."
  principles, pilot call to action, footer.
- Copy follows the brand voice and describes only what Pactlab does — no
  customer logos, statistics, testimonials or claims of live integrations.
- Calls to action that need real addresses (sign in, pilot email) render
  only when configured at build time.
- WCAG 2.2 AA colour pairings, skip link, visible focus, reduced motion.

## Not included

Hosting/DNS for pactlab.ai, analytics, legal pages (privacy, terms) —
those need decisions and content from the founder.
