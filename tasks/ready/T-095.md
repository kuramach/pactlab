# T-095 — Swap brand identity to the locked B2 logo

Context: light

## Decision (locked by Kumar, 2026-10-28)
The flask-with-handshake symbol and the gradient-drift wordmark are retired. The new
mark ("B2") is: an outline round flask whose liquid carries a diagonal gradient
(#2A3AA8 -> #6978FF), with a one-color Manrope ExtraBold wordmark ("pactlab") whose
letterforms are converted to outlines in the SVG — no font dependency at runtime.

Final assets are already committed to `apps/site/public/brand/` (commit 26f4de7c8):
- `pactlab-logo.svg` (ink #081127, for light backgrounds)
- `pactlab-logo-light.svg` (white, for navy/dark backgrounds)
- `pactlab-symbol.svg` / `pactlab-symbol-light.svg` (flask only)
- `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`, `icon-512.png`

Brand colors and typography do NOT change: ink #081127, indigo #6978FF, Manrope.

## Work
1. Find every usage of the old identity: `pactlab-logo.png`, `pactlab-logo-light.png`,
   `pactlab-symbol.png`, and any inline/embedded copy of the handshake-flask symbol —
   across the marketing site, the web app (shell, sidebar, login), favicon links,
   apple-touch-icon, PWA manifest, OG/Twitter social images, email or PDF templates,
   README/docs. Grep the whole repo; list what you found in the PR.
2. Re-point each usage to the new assets. Prefer the SVGs in UI surfaces; use the
   PNGs only where SVG is unsupported (favicon-32, apple touch, OG/social).
   Regenerate any social/OG image that embeds the old logo.
3. Check layout: the new lockup's aspect differs slightly from the old PNG —
   verify header/footer/sidebar heights and alignment did not shift.
4. Delete the three old PNGs once zero references remain.

## Acceptance
- `grep` shows zero references to the old filenames and no handshake symbol anywhere.
- PR includes before/after screenshots: site header (light), a dark surface (footer
  or app login), and the favicon rendered in a browser tab.
- CI green. No other visual or palette changes in the diff.
