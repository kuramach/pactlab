# T-144 — Signing follow-ups from T-136: env documentation and background status polling
Engine: claude
Model: sonnet

Lane: platform
Context: standard
Touches: apps/worker apps/api packages/connectors .env.example docs tasks
Needs: T-136
Checks: pnpm lint && pnpm typecheck && pnpm test

## Why
- T-136 (#242) shipped in-app signing behind a provider seam, BoldSign first. Two pieces were outside its `Touches:`.
- **`.env.example`:** the signing settings are documented only in `docs/runbooks/signing.md`, not in `.env.example`. CLAUDE.md says variable names and explanations go in `.env.example`.
- **Background polling:** status only refreshes when someone opens a pact's LOI or Closing page. An envelope on a pact nobody opens stays at its last known status if a webhook is missed. That breaks the T-125 rule (no silent failures) and T-136's own "polling is the fallback for a missed webhook".

## Build
1. **`.env.example`:** add `SIGNING_PROVIDER`, `BOLDSIGN_API_KEY`, `BOLDSIGN_API_BASE_URL`, `BOLDSIGN_WEBHOOK_SECRET`, and any other setting T-136 added (read `packages/config/src/env.ts`). Each gets a one-line explanation, and no values.
2. **A worker sweep:**
   - **What it does:** a repeatable job in `apps/worker`, for example every 15 minutes, polls each open envelope (sent or delivered) through the same seam as the page-load poll. It reuses the existing idempotent status recording, so a webhook and a poll can never double-apply.
   - **Limits:** a bounded batch per run, with keyset pagination over open envelopes.
   - **No silent failures:** an envelope that can't be polled records the failure where the pact team sees it.
3. **Docs:** update `docs/runbooks/signing.md` (the polling cadence, and what a stuck envelope looks like).

## Acceptance
- A missed webhook still reaches pact state within one sweep, with no page open (test against the fixture provider).
- A webhook and a poll for the same event apply once.
- `.env.example` lists every signing setting.

## Blocked (agent run, 2026-11-25)
CONTEXT-STARVED: the worker sweep needs files outside `Touches:`.
- **`packages/db`:** the worker runs as the runtime role under RLS, so it cannot list open envelopes across tenants. A SECURITY DEFINER function with keyset pagination (like `app_signing_event`) is needed, plus a way to record "could not poll" where the pact team sees it (a new timeline event or audit action, which `signing_envelope_events` and the `audit_events` policy do not allow today). That is a migration, so plan mode and an ADR note apply.
- **`packages/config`:** the worker's env schema has no signing settings, and the sweep needs the BoldSign and fixture adapters built from them.
- **Done in scope:** `.env.example` now lists every signing setting (acceptance 3).
- **Not done:** the sweep, its tests, and the `docs/runbooks/signing.md` update (the cadence and stuck-envelope text describe a sweep that does not exist yet).
- **To unblock:** widen `Touches:` to `packages/db packages/config` (and `infra/cdk` if the worker task needs the secrets).
