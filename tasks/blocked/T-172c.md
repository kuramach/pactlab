Engine: claude

## Why
T-172 built the catalogs and moved the pilot surface (the pact home's own content and Findings). `apps/web/lib/i18n/literals-baseline.json` records what is still inline: about 4,100 literals in 163 files, including the panels the pact home embeds (Sextant explanation, multiple context, negotiation anchors, property metrics, financing posture), the app shell (sidebar, top bar, guided tour), settings, admin, imports, valuation, terms and the What's-new cards. T-173 translates every key, so this comes first.

## Build
1. Surface by surface, move copy into `apps/web/messages/en/<surface>.ts` and read it through `getI18n()`; shared components take `t`. Copy held in data arrays (labels, outcome maps) moves too, though the no-literal check cannot see it.
2. Add each new namespace to the German overlay (machine-made, flagged for review) so German stays offered; or record that German shows English there until T-173, per namespace.
3. Lower the baseline with each PR (`UPDATE_LITERALS_BASELINE=1`); the last PR empties it and the no-literal test then refuses any literal anywhere.

## Acceptance
- `literals-baseline.json` is empty; the English catalog covers the whole app; the existing e2e suite stays green in English.
