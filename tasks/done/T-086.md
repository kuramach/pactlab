# T-086 — Homepage pact carousel: every pact you can run on Pactlab, rotating on the home page

**Lane:** site
**Context:** standard
**Touches:** site
**Needs:** none (cards link to the existing industry pages; the venture-raise page arrives with T-083 — if the carousel ships first, its card links to the industries index until the page exists, then repoints)

## Kumar's ask (2026-10-26)

"We also need a nice carousel on the home page that moves through all the pacts that are possible with Pactlab."

## What it is

A homepage section — working title **"Every pact has two sides. Run yours."** or simply "Pacts you can run" (final copy in the site voice at build time) — with a rotating carousel of pact cards: the core technology acquisition plus the twelve packs. A visitor standing still sees the whole range pass by; the point is breadth at a glance — a hotel deal, a SaaS acquisition, and a founder's seed raise are all the same product.

## The cards (13)

Order is deliberate — flagship first, breadth through the middle, the founder flip as the closer:

1. **Technology acquisition** (the core deal — links to the product/modules page): "Diligence a software company end to end — code, contracts, financials, valuation."
2. **Fintech** — payments/compliance evidence, regulatory posture.
3. **Healthcare services & healthtech** — payer mix, billing integrity.
4. **Telecom & media** — subscribers, churn, content and network assets.
5. **IT & professional services** — utilization, client concentration.
6. **Pharma & biotech** — pipeline, patents, clinical milestones.
7. **E-commerce & DTC** — cohorts, returns, CAC/LTV.
8. **Multifamily** — rent rolls, lease risk.
9. **Commercial property** — lease abstracts, WALT, rollover.
10. **Hotels & hospitality** — RevPAR, franchise terms, PIP capex.
11. **Small clinics** — provider contracts, per-site economics.
12. **Hospitals** — payer-mix-adjusted EBITDA, census, cost reports.
13. **Venture Raise** — the flip side: "You're the one being diligenced. See what the investor will find — first." (links to /industries/venture-raise)

Each card: pack name, the one-line outcome above (final wording at build, site voice — direct, no hype, present tense), the pack's existing illustration (T-051 SVG set — reuse, do not redraw), and the whole card is the link to its industry page.

## Behavior (this is where "nice" is earned)

- **Auto-advance** every ~5 seconds, one card step, smooth transition consistent with the site's motion language — no bounce, no parallax gimmicks.
- **Pauses** on hover, on focus, and permanently after any manual interaction until the visitor leaves the section; **respects `prefers-reduced-motion`** (no auto-play at all, manual stepping only).
- **Controls:** previous/next buttons and dot indicators, all keyboard-operable with visible focus, correct ARIA (`aria-roledescription="carousel"`, labelled slides, aria-live off for auto-rotation so screen readers aren't spammed).
- **Touch:** swipe works; the carousel never traps scroll.
- **Responsive:** one card on mobile with a peek of the next (so it reads as a carousel, not a page), 2-3 across on desktop per the grid.

## Performance and correctness

- No carousel library — build on CSS scroll-snap / transform + a small controller in the site's existing stack. No layout shift (fixed card aspect, reserved space), illustrations lazy-loaded except the first visible card, and the section must not dent the home page's Core Web Vitals (T-085 budgets apply).
- Every card link resolves against the built routes — the PR includes a link check over all 13 cards.

## Guardrails

- Marketing site only; no app changes. Copy follows the standing posture (present tense, available, no invented claims or stats).
- If a pack page doesn't exist yet when this ships, that card links to the industries index — never a 404, never a placeholder page.

## Acceptance

- All 13 cards render in order with the packs' existing illustrations; auto-rotation, pause-on-hover/focus, manual controls, swipe, and reduced-motion behavior all verified.
- Keyboard + screen-reader pass on the controls; Lighthouse home-page budgets (T-085) still met with the carousel live.
- Link check: 13/13 cards resolve to real routes.
