Checks: pnpm lint && pnpm typecheck && pnpm test && pnpm test:fixtures

## Brief

Build the spine everything else hangs off: deals, evidence, lineage.

- Deals: CRUD, memberships (buyer-side roles), contributor boundaries
  (target contributors are isolated from buyer-only data unless shared).
- Connections: per-deal `FIXTURE`/`LIVE` mode persisted and audited;
  `validateConnection()` and `dryRun()` on the connector contract.
- Sync runs: idempotent, replay-safe BullMQ jobs. Replaying a run creates zero
  duplicates (prove with a test).
- Evidence: normalized evidence items with source citations and lineage
  (every record resolves to its source system + record id).
- CSV ingest as the first evidence source (fixture mode).
- Evidence browser UI: list, filter, and lineage view per item.
- Begin `pnpm seed`: idempotently create stable cross-system HealthyCo /
  TroubledCo / SparseCo identities (stub data is fine; T-003+ fills it in).

## Acceptance

- Replay-a-sync-run test: no duplicates, lineage intact.
- Every evidence record resolves to its source (test).
- Reviewer can open the evidence browser, pick an item, and see its full
  lineage back to the source system.

## Out of scope

Metrics, findings, valuation, document AI, live provider credentials.
