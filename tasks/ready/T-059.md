Build the Multifamily pack on the T-057 framework (definition: spec §19 and
ADR 0008 where it applies). Start with the §19 spec amendment the activation
bar requires: import targets, finding types, valuation adjustments, fixtures
and the acceptance journey below.

## Import targets (CSV, ADR 0010)

Column layouts match the published demo data
(`kuramach/pactlab-demo-data/multifamily/`), so its files import as they are:
  - `rent-roll.csv — units, leases, in-place and market rents, balances`
  - `t12.csv — trailing-twelve-month operating statement`
  - `delinquency.csv — delinquent balances`
  - `unit-inspections.csv — condition and repair estimates`
- plus the billing import on the Pactlab standard template, unchanged.

## Finding types (deterministic detection → draft findings, humans decide)

  - Offering-memorandum NOI above the T-12
  - Deferred maintenance above the capital plan (per door)
  - Delinquency concentration by building
  - Loss-to-lease — +1 confirmed value, never a price increase

## Valuation

  - New core valuation method: NOI ÷ capitalization rate, with cap-rate sensitivity (registered through the T-057 method interface, deterministic, decimal)
  - Metric calculator: occupancy, loss-to-lease, NOI, delinquency, capex per door
  - Capex per door lands as remediation (−1)

This is one of the two framework-shaping packs (first non-revenue imports
and first non-ARR valuation): record every framework gap in the PR and in
T-060 rather than working around it. Residents appear only as units.

## Acceptance

- Import every file in `pactlab-demo-data/multifamily/<USD|EUR|GBP>/` into a
  fresh deal with that pack and base currency; each planted finding in that
  folder's README surfaces as a cited draft finding, and accepting it reaches
  the valuation with the stated direction.
- Extend the demo-data contract test (`apps/api/src/ops/demo-data.test.ts`)
  so this pack's extracts import cleanly through their targets.
- Synthetic data only.

## Out of scope

- Direct connections to industry systems (property-management, PMS/STR,
  core-banking, EHR/RCM, …). Packs start with file imports (Kumar,
  2026-10-22); live adapters come later behind the same import targets.
