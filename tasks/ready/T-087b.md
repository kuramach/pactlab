# T-087b — Billing follow-ups: read-only after the live period, nightly reconcile, banners
Engine: claude

**Lane:** platform
**Context:** standard
**Touches:** api (deal access), infra (scheduled task), web
**Needs:** T-087 (merged)

1. **Read-only after the live period:** past `deals.live_until`, every write to that pact is refused with a clear code, and reads keep working. This needs one central check that every write path goes through; today's `DealAccess.require` can't tell a write from a read. Reopening an expired pact is a later purchase option.
2. **Nightly reconcile:** schedule `src/ops/billing-reconcile.ts` (an EventBridge-scheduled ECS task, owner credentials) on stage and live.
3. **Banners:** "This pact's live period ended" on expired pacts, and a past-due banner across the app for org admins.
4. **Refunds:** a refunded one-time purchase voids its unused credit (`charge.refunded` webhook).
