# T-042 — Company logos on the billing-export upload form

Status: ready
Needs: none
Touches: apps/web tasks
Lane: web-ux

- The billing-export upload form (`apps/web/app/(app)/deals/[dealId]/sources/upload/page.tsx`)
  lists each source system as a text-only radio card. Show the company's
  logo/icon on each card, next to the system label, so the picker is scannable
  at a glance.
- One logo per system id returned by `dealsApi.billingSystems()` (NetSuite,
  Zuora, Chargebee, SAP S/4HANA, SAP ECC, Oracle Fusion, QuickBooks, plus the
  generic/other entries). Key the mapping by the API's `system` id.
- Self-contained assets only: inline SVG brand marks (simple-icons style paths)
  in a web component, monochrome/currentColor so they sit inside the existing
  navy/indigo design; no external image URLs and no runtime CDN fetches.
  A system with no brand mark gets a lettered monogram tile in the same slot —
  never a broken image.
- Card layout, Verified/Suggested badges, export hints and radio behaviour stay
  unchanged. The logo is decorative (`aria-hidden`); the system label remains
  the accessible name.
- Test: a contract test asserting every system id the API can return resolves
  to a logo or monogram entry — an unmapped id fails the build (same pattern
  as the valuation-direction registry test in T-037).
