# T-016 — Jira (fixture-first), sources per deal, sample data for email-code orgs, spec branding

Status: done
Needs: T-015
Touches: packages/connectors packages/domain/src/evidence packages/db/src/seed packages/ui apps/api/src/connections apps/web tasks
Lane: integrations
Checks: pnpm lint && pnpm typecheck && pnpm test && pnpm test:fixtures && pnpm test:integration

## Why

Signed in to the email-code organization, the founder saw nothing: all
sample data lived in the Auth0 organization, Jira did not exist, and no page
showed a deal's connected systems. The UI also did not follow the spec's
brand and visual system.

## What

- **Jira connector** (`packages/connectors/src/jira`): normalized adapter,
  deterministic fixture sites (HealthyCo steady; TroubledCo falling
  completion, growing bug backlog, stale Highest bugs, reopens; SparseCo
  unestimated work, open-ended sprint, unreadable project), config-only live
  adapter (no provider calls until verified against Atlassian docs).
  Evidence `delivery.issue` / `delivery.sprint` with a `provider_record`
  locator. **No people data**: no assignee, reporter, summary, description
  or comments.
- **API**: one sync-adapter interface for CSV, GitHub and Jira; per-provider
  config validation; `GET /connections` now returns each connection's last
  sync run and evidence count.
- **Seed**: every target (HealthyCo, TroubledCo, SparseCo) gets billing/KPI
  CSVs, a GitHub repository and a Jira site in both Alpha (Auth0) and
  Charlie (email code, derived ids). SparseCo's repository is the
  partial-permission fixture: a recorded FAILED sync, not an abort; re-seeding
  writes nothing new.
- **Web**: per-deal Sources page (provider, mode, health in words, evidence
  and issue counts, failure hints); deals list links Sources / Evidence /
  Finances.
- **Branding (brand kit `brand/BRAND.md`)**: official logo artwork (wordmark,
  reversed wordmark, flask-and-handshake symbol as favicon), deep navy
  #081127 and indigo #6978ff, Manrope, tagline "Test the pact before you
  sign it."; plus the spec's visual rules (tabular numerals, 4/8 px radii,
  visible focus, reduced motion). Brand indigo on white is 3.66:1, so
  indigo buttons carry navy text (5.12:1) and indigo links use #4a58e8
  (5.45:1) to meet WCAG 2.2 AA.

## Out of scope

Delivery metrics and people/contributor views (spec phase 2), live Jira and
GitHub reads.

## Note

The brand kit's tagline matches CLAUDE.md; the spec's older tagline ("Every
deal is a pact. Make it an honest one.") is not used.
