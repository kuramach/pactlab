# T-177b — Console pricing screen: edit and publish price books per market, with history

Engine: claude
Model: opus
Lane: platform
Context: standard
Touches: apps/web apps/api packages/contracts docs tasks
Needs: T-177a
Checks: pnpm lint && pnpm typecheck && pnpm test && pnpm test:integration && pnpm test:e2e

## Why
Kumar edits prices himself, without a deploy (T-177's acceptance). T-177a stores the versioned books and promos; this is the screen.

## Build
- **Console → Pricing** (platform operator only; check authorization server-side):
  - **Market switcher:** USD, GBP, EUR, JPY or INR.
  - **The current book:** the fixed fee, the bands with their basis points, the cap and pilot pricing.
  - **Editing:** produces a draft version; **Preview** quotes sample deal sizes ($10M, $25M, $50M, $100M, $250M, $500M, or the same in the market's currency) against the draft and the live version side by side; **Publish** makes it live.
  - **Version history,** with who changed what and when.
- **Promos:** list, create, pause and expire, with each one's scope, window, cap and redemptions.
- **Patterns:** built from the approved patterns in `docs/ui-patterns.md`.

## Acceptance
- Kumar edits the USD fixed fee, previews, publishes, and a fresh quote uses it, while a quote made before keeps its price.
- A non-operator gets 403 from the API, and the page isn't shown.
- An e2e journey covers edit → preview → publish.
