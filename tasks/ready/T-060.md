## Gaps recorded by T-058 (fintech)

- **Fixed in the core during T-058:** findings can cite a document page by
  exact quote (`finding_evidence_links.document_citation`, verified with
  `SourceIndex` on record and on acceptance); rules read readable document
  pages (`RuleContext.pages`, never HR/pay/performance classes); pack upload
  connections pass the credential check (`pack_upload`).
- **Rule code lives in `@pactlab/calculations`** (decimal arithmetic) with
  mirrored types (`packs/rule-types.ts`); the API composes them into the
  domain registry. Decide whether a small shared package should own the rule
  types instead of the mirror.
- **Document matching is sentence-based on collapsed text** (PDFs wrap
  lines): an unpunctuated heading joins the next sentence. Fine for quotes;
  revisit if a pack needs structure (tables) from documents.
- **Unpriced drags:** a rule may propose −1 without a price when no
  defensible amount exists (AML); acceptance then refuses until a person
  prices it. Consider a "needs pricing" state in the findings UI.
- **`pack_upload` connections have no source kind** in the source plan
  (`catalog.ts` `matchesProviders`); they list under connected sources only.
- **Findings page "Run … checks"** is manual; consider running a pack's rules
  after each import.
