# T-006 — Document AI (MVP Increment 5)

Status: ready
Needs: T-002
Touches: apps/api/src/documents packages/ai apps/web/app/(app)/documents
Lane: docai
Checks: pnpm lint && pnpm typecheck && pnpm test

## Brief

Contracts and data-room documents become cited evidence.

- Secure uploads (tenant-scoped storage, virus-scan hook point, retention
  controls).
- Extraction pipeline: pages, exact page-level citations. An AI output without
  a resolvable citation can never become an accepted finding (enforce in code).
- Claude gateway (`packages/ai`): versioned prompts (prompt registry), typed
  structured outputs, model routing (Sonnet default; per spec).
- Q&A over documents with citations; contract extraction (parties, dates,
  key clauses) as draft findings; human review queue.
- Evals: a small golden set proving citation accuracy; run in CI.

## Acceptance

- Every accepted AI finding carries exact page citations + a named human
  reviewer (test).
- Citation-mismatch and prompt-injection probes are tested and blocked.

## Out of scope

VDR integration (T-007), HR/compensation data (never in prompts — see
people-data rules).
