## Build (after approval)
- **Price books:** versioned, per currency (USD, GBP, EUR, JPY, INR), each with an effective time.
  - **A version is immutable once it has quoted.** Editing creates a new version.
  - **An in-flight quote keeps its version's price.**
- **Promo codes,** in every kind the engine knows:
  - percent off the total;
  - percent off the fixed fee;
  - an amount off;
  - the variable waived;
  - a pilot-flat override.

  Each code has currency scope, a window, a redemption cap and stacking rules; reseller codes stay with T-093.
- **Quotes stored:** each one keeps its inputs, the book version and the result lines, so a quote can be re-shown exactly.
- **API:**
  - read the current book per currency;
  - quote a pact (the engine plus the stored book);
  - for the platform operator only, create a draft version, publish it, and manage promos.

  Every write is audited.
- **Migrations:** expand-only. Money is numeric with currency and scale; RLS lets the platform operator write, and any organization reads only what it needs to quote its own pacts.

## Acceptance
- Publishing a new USD book version changes fresh quotes with no deploy; an existing quote is re-shown unchanged.
- Editing a version that has quoted is refused; a new version is created instead.
- A JPY-scoped promo applies to a JPY pact and not to a USD one.
- The audit log shows every book and promo change.
