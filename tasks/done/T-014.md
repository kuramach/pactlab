# T-014 — Seeded code findings and a local decision-loop walkthrough

Status: done
Needs: T-013
Touches: packages/domain/src/evidence packages/connectors/src/github packages/db apps/api/src/local-flow.ts apps/api/package.json pnpm-lock.yaml tasks
Lane: findings
Checks: pnpm lint && pnpm typecheck && pnpm test && pnpm test:fixtures

## Why

After T-011..T-013 the local database had evidence but no findings, and no
code evidence for a finding to cite honestly: the only source locator was a
CSV row and the scanner produced no evidence items. The web pages for
findings and valuation are read-only, so the review steps could not be
exercised locally.

## What

- **`git_commit` source locator** (`packages/domain`): one exact commit of
  one repository, never file contents. `describeLocator()` formats either
  kind for lineage.
- **`createGitHubEvidenceSource`** (`packages/connectors`): one
  `code.repository_head` evidence record per analysed head, through the same
  `EvidenceSource` port and sync engine as CSV.
- **Seed** (`pnpm seed`): GitHub fixture connection on Project Troubled,
  repository-head evidence via the real sync engine, and the ghost-commit and
  key-person signals recorded as **DRAFT, unpriced, SYSTEM-authored**
  findings citing that evidence and the head commit. Idempotent by
  fingerprint. Adds a seeded REVIEWER on Project Troubled so decisions can
  be made by someone other than the author.
- **`pnpm --filter @pactlab/api flow:local`**: dev-only walkthrough through
  the production `AppModule` — price the draft, submit, second-person
  accept, valuation scenario linked to the accepted risk, run, freeze,
  second-person approve. Refuses to run unless `APP_ENV=local` and both
  database URLs are localhost; tokens are signed with a throwaway in-process
  key. Identities are looked up by seeded user id, so it keeps working after
  the seeded lead is linked to a real Auth0 login.

## Out of scope

- Web forms for pricing, review and valuation (pages stay read-only).
- Scanner-orchestrator writing evidence items for its own findings.
