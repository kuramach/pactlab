# T-177c — Quote to checkout: itemized fixed and variable lines in Stripe

Engine: claude
Model: opus
Lane: platform
Context: deep
Touches: packages/connectors apps/api apps/web packages/contracts docs tasks
Needs: T-177a, T-093, T-087b
Checks: pnpm lint && pnpm typecheck && pnpm test && pnpm test:integration && pnpm test:e2e

## Why
A pact's price is computed per deal (T-177), so checkout can't use one fixed Stripe price id. It needs the quote's own lines.

## Build
- **Checkout** starts from a stored quote (T-177a) and sends Stripe Checkout itemized `price_data` line items: the fixed fee, and the variable for each band. Check the Stripe Checkout API against the installed SDK types and Stripe's docs before writing code.
- **The quote's currency** is the Stripe currency, and amounts follow Stripe's minor units (JPY has none).
- **Discounts:**
  - a promo (T-177a) or a reseller code (T-093) applies to the sum as the engine computed it;
  - only the better single discount applies, and both effects are itemized;
  - reseller commission accrues on the discounted collected amount (T-093 Part 7).
- **Refunds:** void the quote's redemption and follow T-087b.
- **Connector seam:** behind the existing payments seam, with a fixture adapter. CI runs in Stripe test mode via the fixture, never live.

## Acceptance
- **A $100M pact:** checkout shows $5,000 fixed and $27,500 variable, $32,500 in total, in Stripe test mode.
- **A ¥10B pact:** checks out in whole yen.
- **Promo and reseller codes together:** a 20% promo plus a reseller code attributes the customer to the reseller, applies the better discount, itemizes both effects, and accrues the commission correctly.
- **A refund:** voids per T-087b.
