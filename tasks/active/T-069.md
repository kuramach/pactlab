# T-069 — Hospitals pack

Status: active
Needs: T-061
Touches: packages/domain packages/calculations packages/connectors apps/api apps/web docs/spec fixtures scripts/demo-data tasks
Lane: packs
Context: standard
Checks: pnpm lint && pnpm typecheck && pnpm test && pnpm test:integration && pnpm test:fixtures

Build the Hospitals pack on the T-057 framework (definition: spec §19 and
ADR 0008 where it applies). Start with the §19 spec amendment the activation
bar requires: import targets, finding types, valuation adjustments, fixtures
and the acceptance journey below.

## Import targets (CSV, ADR 0010)

Column layouts match the published demo data
(`kuramach/pactlab-demo-data/hospitals/`), so its files import as they are:
  - `census.csv — admissions, patient days and ADC by service line`
  - `payer-mix.csv — gross charges and net revenue by payer`
- plus the billing import on the Pactlab standard template, unchanged.

## Finding types (deterministic detection → draft findings, humans decide)

  - Earnings concentrated in one payer
  - Accreditation does not transfer automatically (citation)
  - Key-physician dependence (aggregate)
  - Committed regulatory capex (−1 remediation)

## Valuation

  - Payer-mix-adjusted EBITDA (new method through the T-057 interface); regulatory capex as remediation

Extends the healthcare pack (T-061). Physician data is aggregate only; no
patient-level data; nothing sent to a model (rule 7).

## Acceptance

- Import every file in `pactlab-demo-data/hospitals/<USD|EUR|GBP>/` into a
  fresh deal with that pack and base currency; each planted finding in that
  folder's README surfaces as a cited draft finding, and accepting it reaches
  the valuation with the stated direction.
- Extend the demo-data contract test (`apps/api/src/ops/demo-data.test.ts`)
  so this pack's extracts import cleanly through their targets.
- Synthetic data only.

## Out of scope

- Direct connections to industry systems (property-management, PMS/STR,
  core-banking, EHR/RCM, …). Packs start with file imports (Kumar,
  2026-10-22); live adapters come later behind the same import targets.

## Done (2026-10-25)

- Targets `HOSPITALS_CENSUS` (month + service line) and `HOSPITALS_PAYER_MIX` (month + payer); expand-only migration `20261108000000_hospitals_pack`.
- Four rules: payer concentration from the payer mix, accreditation does not transfer (clause), key-physician dependence (aggregate clause), committed regulatory capex (priced remediation from the cost report); healthcare's director-fee and privacy rules also run.
- New valuation method `PAYER_MIX_EBITDA` (engine, validation, API schema, scenario form, explanation, sensitivity on EBITDA and multiple); ADR 0009 addendum; spec §19 11a.
- With every pack built, the "planned industry" API test now covers OTHER.
- Acceptance `apps/api/src/packs/hospitals.acceptance.api.test.ts`; e2e `apps/e2e/specs/hospitals-pack.spec.ts`.
