# T-076 — PDF side-by-side review with the quote highlighted (pilot bug 7)

**Lane:** core
**Context:** standard
**Touches:** api (documents), web (documents), e2e
**Needs:** T-075

## Why (Kumar, 2026-10-24)

Reviewers judged AI drafts against extracted text only. They want the original PDF page beside the queue, with the cited quote highlighted.

## Done

- **API:** `GET /v1/deals/:id/documents/:documentId/original`:
  - same access rules as page reads; a contributor sees shared documents only;
  - the sha256 is re-checked, and each read is audited as `document.original_read`;
  - a purged document returns 410;
  - served inline with `nosniff`.
- **Web:**
  - a server-side proxy route, so the browser never holds the token;
  - `PdfPageView` (pdf.js 6.4.299, read-only), which draws the page and highlights each cited quote using the same whitespace-insensitive matching as `SourceIndex`;
  - the extracted text sits one click away;
  - Previous and Next quote step through the cited pages.
- **Tests:**
  - API: allow and deny, purge, audit;
  - unit: the quote matcher;
  - e2e: a synthetic PDF renders as its original page.

## Checks

`pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm test:e2e`.
