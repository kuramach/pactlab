# T-080 — Browser (Playwright) end-to-end tests

**Lane:** core
**Context:** standard
**Touches:** apps/e2e, ci, root scripts, .env.example, small web fixes found by the specs
**Needs:** none

## Why (Kumar, 2026-10-24)

"Add it now for full browse test." The pilot test found screen bugs that unit
and API tests missed (mapping screen hard-wired to billing; debt entry not
saved). Browser tests now guard the flows a user clicks through.

## Scope

- `apps/e2e` with `@playwright/test` 1.64.1 (Apache-2.0), Chromium only.
- An isolated `pactlab_e2e` database, its own ports and mail folder, a production web build.
- Specs:
  - email-code sign-in and sign-out;
  - billing upload, map, check and import, with an idempotent re-import;
  - fintech loan-tape mapping (regression), and industry checks drafting a cited finding once;
  - cancelling an upload;
  - a data-room document and the AI-off message;
  - a balance-sheet debt item, with the quote picker, a field error that keeps the input, and the item persisting;
  - cross-tenant isolation through a newly signed-up and approved organization.
- A CI `e2e` job (after `build`); artifacts are uploaded on failure.

## Bugs the specs found (fixed here)

- The wizard skipped the Review step: the last Next became the submit button mid-click.
- Re-importing the same file showed "N new records"; it now says nothing changed.

## Checks

`pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm test:e2e`, plus the CI `e2e` job green.
