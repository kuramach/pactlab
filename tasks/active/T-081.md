## Bugs (Kumar's pilot test, 2026-10-24)

- **#2:** imports accepted CSV only. Support a couple of standard formats.
- **#5:** documents accepted only PDF, Word, text and Markdown.
- **#3:** files of 10K–100K lines need a batch flow with progress.

## Done

- **Imports:**
  - comma, semicolon or tab separated text;
  - UTF-8, falling back to Windows-1252;
  - `.xlsx` with a sheet picker: exact decimals, ISO dates, zip-bomb and macro guards;
  - `.xls` and `.xlsm` refused with how to fix it;
  - files up to 50 MB.
- **Documents:** `.xlsx` (each sheet is a page) and `.csv`.
- **Background imports:**
  - more than 5,000 rows run on the worker (`upload.import`) through the same `runUploadImport` as inline imports;
  - progress is kept on the BullMQ job (counts only);
  - the mapping screen polls it;
  - a failed run can be retried.
- **Slow tests run only at promotion** (Kumar, 2026-10-24):
  - `@slow` specs are excluded from PR CI;
  - `e2e-full.yml` runs them nightly, on demand, and is meant to be called by the promotion pipeline.
- **Migration** (expand only): `source_uploads.format` and `sheet`; the document content-type check is widened.
