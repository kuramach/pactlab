# T-001 — Foundation (MVP Increment 0)

Status: ready

## Brief

Scaffold the Pactlab monorepo per `CLAUDE.md` (Repository layout) and the spec.
Strict TypeScript everywhere (`strict: true`, no implicit any).

- `apps/web`: Next.js App Router shell + Tailwind + shadcn/ui + design-system
  shell page. No product screens yet.
- `apps/api`: NestJS + Fastify skeleton, health endpoint, Auth0 wiring.
- `apps/worker`: BullMQ + Redis skeleton, one no-op job proving the queue works.
- `apps/scanner-orchestrator`: stub that accepts a scan request and returns a
  typed "not implemented" result (real runners come in T-004).
- `packages/`: `domain`, `contracts` (shared Zod schemas), `db` (Prisma),
  `connectors` (adapter interface + fixture/live contract), `ai` (Claude gateway
  stub), `calculations` (decimal money helpers — never float), `ui`,
  `observability`, `config` (env validation at startup).
- Prisma schema: organizations, deals (with `transaction_type` enum:
  `PUBLIC_ACQUIRER | PRIVATE_ACQUIRER | TAKE_PRIVATE`), memberships, audit log,
  outbox. PostgreSQL RLS: every deal row carries organization + deal identity.
- `infra/cdk`: TypeScript CDK app with a dev stack (VPC, Postgres, Redis).
  Synthesize only (`cdk synth`) — do not deploy. Local-first: no AWS
  deployment until T-007. No stage/prod resources yet.
- `.github/workflows/ci.yml` exists (starter provided); make it green.
- `fixtures/synthetic/`: empty `HealthyCo/`, `TroubledCo/`, `SparseCo/`
  directories with a README describing what each will prove (seeded in T-002+).
- `.env.example`: variable names + explanations only. No secrets.

## Acceptance

- `pnpm lint`, `pnpm typecheck`, `pnpm test` all green; CI green on the PR.
- RLS proof: a test with two synthetic tenants where tenant A cannot read
  tenant B's deals, jobs, files, or search results — allow AND deny paths.
- `pnpm dev` boots web + api + worker against local Postgres/Redis.

## Out of scope

Any product feature, any live provider integration, stage/prod infra.
