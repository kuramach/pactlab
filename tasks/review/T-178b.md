## Why
T-178 shipped the rinse engine, the manifest and its injection (ADR 0058). Its login, invite and build parts need schema, auth and CI changes outside T-178's scope. Plan mode first: this is auth and schema.

## Build
1. **Preparer account.** A free account with the same passwordless email code or passkey auth (ADR 0001, 0023). It holds no pact access: a preparer sees only their own bench sets and invites. Expand-only migration.
2. **Prep invite.** A link or QR from the pact (buyer side) that creates the account and binds it to the inviting org and deal in one step. It deep-links to `pactlab.ai/rinse`. The binding is stamped into the manifest's `set.intendedPact`, and the sync refuses a manifest bound to another pact.
3. **Desktop sign-in** in the Tauri shell, with the session cached for offline use. AI steps and uploads queue while signed out or offline (`AiQueue` already does this).
4. **AI rinse jobs:** an API endpoint for classification and the vision lane under the preparer account. Metered, under the ADR 0034 data terms, rate-limited per account. Implement `RinseAiClient` against it.
5. **Upload to a Pactlab-hosted deal room** when that is the chosen destination.
6. **The shell:** bundle the renderer, and run the engine as a Node sidecar. Bundle LibreOffice (headless) and an OCR tool.
7. **Builds in CI** on macOS (Apple Silicon and Intel), Windows and Linux: Developer ID signing and notarization, Windows code signing, and the Tauri updater key. Record honestly in `docs/runbooks/rinse.md` what is signed.


## Decisions (Kumar, 2026-11-27): build, don't stop
The first run stopped for four decisions; they're now recorded in **ADR 0059**, accepted in this PR, under "Kumar's decisions":
- uploads go to the seller's own storage only;
- signing uses Apple's $99 plan and Azure Artifact Signing Basic for Windows;
- the converters (LibreOffice and Tesseract) are bundled;
- there's no Rinse billing, because AI jobs count against the pact, which is already paid for.

Build to ADR 0059 as accepted. Where the plan conflicted (a Pactlab-hosted room), follow decision 1.
