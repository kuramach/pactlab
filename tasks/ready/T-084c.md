# T-084c — MCP client mode: external MCP servers as evidence sources (T-084 Part 3)
Engine: claude

**Lane:** platform
**Context:** deep
**Touches:** connectors, api (connections), docs
**Needs:** T-084 Part 1 (merged)

Pactlab consumes an operator-allowlisted external MCP server as a read-only evidence source under the connector framework:
- **Allowlist:** operator-set, never a URL a user types, with the same SSRF posture as T-082 and the CIMD fetcher.
- **Pipeline:** output is normalized into evidence through the existing pipeline, and VALUATION_DIRECTION_MAP registration is needed before any finding.
- **Scope:** one mainstream reference server end to end, plus the registration pattern documented.
