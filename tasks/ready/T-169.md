# T-169 — Engineering evidence window: Git and Jira pulls default to the last 2 years

Engine: claude
Model: sonnet
Lane: platform
Context: standard
Touches: packages/connectors apps/api apps/web docs
Needs: none
Checks: pnpm lint && pnpm typecheck && pnpm test && pnpm test:integration

## Why

Kumar's direction (2026-11-26): engineering evidence should describe the team that is actually there. Beyond about two years, contributors have often left and the history stops describing the current team — it misleads key-person, bus-factor and activity analysis. So the GitHub and Jira pulls default to a two-year window, and a longer pull is an explicit choice, never the silent default.

## Build

1. **Default lookback of 24 months** in the GitHub and Jira live adapters (`packages/connectors`): commits, pull requests, issues, and Jira issues/sprints/worklogs are queried only inside the window. The window is computed at sync time, not stored per record.
2. **Per-connection override.** The evidence-source configuration gains a lookback setting (months; default 24; a deliberate longer value, or all-history, is selectable when the source is connected or edited). The setting is shown wherever the source's sync is described in the UI, so a reviewer can see which window a finding rests on.
3. **Findings carry the window.** Engineering findings that aggregate history (contributor concentration, activity trends) record the window used, so a 24-month finding is never silently compared with an all-history one.
4. **Out of scope, explicitly:** the T-127 Kafka demo pack is a frozen one-time pull and stays exactly as cached; recorded-cassette tests keep working (fixtures may be re-recorded in the repo's established way if a query shape changes); demo data is unaffected.

## Checks

- Adapter unit tests: window boundaries (a record at 23 months is in, at 25 months is out, under the default), the override value honoured, all-history only when explicitly set.
- API tests: the setting round-trips on source create/edit and defaults to 24 when unset.
- The existing connector and engineering-pack suites stay green.

## Acceptance

- A fresh GitHub and Jira sync against a test workspace pulls only the last 24 months by default.
- Setting a connection to a longer window (or all history) and re-syncing pulls the longer history, and findings record the window used.
- Runbook/docs note the default and the rationale (stale history misleads team analysis) where evidence sources are documented.
