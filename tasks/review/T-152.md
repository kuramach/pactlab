# T-152 — Import prompting: guide the AI mapper with instructions, down to the row (Excel/CSV first)

Engine: claude
Model: sonnet
Lane: platform
Context: standard
Touches: apps/web apps/api packages/ai docs
Needs: none

## Why

The import assistant (PR #254) maps real-world spreadsheets and asks when unsure, but the user has no way to steer it up front. Kumar's direction (2026-11-24, first of an immediate set): let the user give the AI nice, explicit prompting when importing — especially Excel and CSV — including specifying things by row, instead of correcting a wrong mapping after the fact.

## Build

1. **Import-level instructions.** The import flow gains an optional free-text instruction field ("Anything the AI should know about this file?") with a few one-click starter prompts (e.g. "First row is not a header", "This is a rent roll, one row per unit", "Amounts are monthly"). The text is passed to the import-mapping job as user guidance, visibly quoted back in the mapping preview so the user can see what the AI was told.
2. **Row and range annotations.** In the mapping preview grid for Excel/CSV imports, the user can select rows (or a range) and attach an instruction: e.g. "rows 1–3 are title/header rows, skip them", "row 14 is a subtotal, not data", "rows 5–40: column B is the tenant name". Annotations are sent to the mapper as structured guidance alongside the free text. Keep the interaction simple: select rows, type, save — no formula language, no new grid editor.
3. **The mapper honours guidance — and says so.** The mapping result marks which fields/rows were determined by user guidance vs inferred vs asked-about. Where guidance conflicts with the data (e.g. the annotated subtotal row doesn't sum), the existing ask-when-unsure path fires with the conflict stated, rather than silently overriding either way.
4. **Guidance persists with the import.** Instructions and annotations are stored on the import record, shown in the import's detail view, and reused automatically if the same file is re-imported (see T-154 for delete/re-import semantics), with the user able to edit them before the re-run.

## Guardrails

- Guidance steers mapping only. It never changes the imported values themselves, and the deterministic tie-outs (subtotals, totals) still run and still flag mismatches.
- Instructions are user content: stored with the import, visible to the pact's members per existing permissions, never sent anywhere except the mapping job.
- Works for the existing import kinds (P&L, rent roll, generic spreadsheet); PDF imports are out of scope for row annotations.

## Checks

- Tests: guidance reaches the mapping job (fixture import with an instruction that changes the outcome), row annotation parsing and range handling, conflict path asks instead of overriding, guidance round-trips on re-import.
- Screenshot the import flow with the instruction field and an annotated grid at desktop width.

## Acceptance

- A user importing an awkward CSV can state "row 1 is a title, amounts are annual" up front and watch the mapping follow it, with guided fields marked as guided.
- A wrong subtotal annotation produces a question, not a silent wrong import.
