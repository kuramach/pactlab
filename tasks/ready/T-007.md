## Brief

Make it safe to put a real deal on the platform.

- VDR adapter (Datasite or equivalent) behind the connector contract —
  fixture-first like everything else.
- Retention controls, audit export, SSO (Auth0), access reviews.
- Metering: per-deal AI token accounting (the pricing model bills per deal).
- Pilot controls: feature flags / pilot-mode guardrails, rollback runbooks in
  `docs/runbooks/`.
- Penetration-test checklist and recovery drill documented as runbooks.
- Stage/prod CDK stacks with termination protection on stateful resources;
  deployment only via GitHub Actions (per CLAUDE.md AWS environments).

## Acceptance

- A limited design-partner pilot can be described end-to-end: controls,
  audit export, and rollback path all documented and demonstrable.

## Out of scope

Phase 2 (HRIS/Jira), Phase 3 (sourcing/100-day plans), new diligence modules.
